This repository contains a prototype for an Explainable AI (XAI) Medical Diagnostic Dashboard designed to assist in detecting pneumonia from chest X-ray scans. Built as a student academic project, the goal of this application is to bridge the gap between black-box deep learning models and clinical interpretability. By utilizing transfer learning and generating neural activation maps, the system not only predicts the presence of pneumonia but visually explains where the model is looking to make that prediction.Core FeaturesDeep Learning Inference: Utilizes a custom PyTorch model built on the ResNet50 architecture, modified to output a binary classification for Normal vs. Pneumonia.   Explainable AI (Grad-CAM): Implements Gradient-weighted Class Activation Mapping (Grad-CAM) to generate heatmaps that highlight the regions of the lung influencing the AI's decision.   Interactive Clinical Interface: Features a vibrant, glassmorphism-styled Streamlit UI named "RadixAI", complete with dynamic patient demographic inputs, inference metric visualizers, and simulated EMR export capabilities.   Automated Clinical Findings: Dynamically generates clinical impressions, confidence intervals, and suggested next-step protocols based on the AI's primary prediction.   Unit Testing Setup: Includes a pytest suite designed to validate model initialization, ensure correct image tensor shapes, and verify the normalization constraints of the heatmap generations.   Technology StackThis project relies on the following key libraries:   Deep Learning: torch, torchvisionFrontend Framework: streamlitComputer Vision & Imaging: opencv-python-headless, PillowData Processing: numpy, pandas (for telemetry mapping in the UI)Testing: pytest
